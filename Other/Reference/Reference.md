## Features

This section lists the features one would typically expect from a product like ScriptCollection (a collection of reusable scripts and build-/CI-automation).
The `state`-column reflects whether the feature is available (`available`) or only planned (`unavailable`), based on the documentation.

| id     | state     | description                                                                                                    |
| ------ | --------- | -------------------------------------------------------------------------------------------------------------- |
| feat-1 | available | Reusable collection of scripts and command-line tools for development- and operations-automation.              |
| feat-2 | available | Building codeunits of a common-project-structure repository via `scbuildcodeunits` (also containerized).       |
| feat-3 | available | Running a command for each entry of a folder via `scforeach`.                                                  |
| feat-4 | available | Printing file-content in a controlled way via `scprintfilecontent`.                                            |
| feat-5 | available | Remote-build support: running a build on a remote task-runner and writing the result back into the repository. |
| feat-6 | available | Downloading and providing external build-tools (for example JRE, TruffleHog, MediaMTX, FFmpeg, GRYLibrary).    |
| feat-7 | available | Generating a bill-of-materials (BOM) for codeunits during the build.                                           |
| feat-8 | available | Managing docker-based local test-services for builds and tests.                                                |
| feat-9 | available | Generating certificate-authorities and certificates via the ScriptCollection-core.                             |
