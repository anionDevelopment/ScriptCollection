# Release notes

## Changes

- `scrais` can restrict the network-access of the sandbox to an allowlist of domains: the section `AllowedDomains` in `AgentSandboxConfiguration.ini` with one entry per domain (`<domain> = <comment>`, the comment is optional) or `--alloweddomain` (repeatable, replaces the list of the configuration-file). If an allowlist is defined, everything except the allowlist is blocked: only the listed domains are reachable, only via HTTPS (port 443), through an egress-proxy (Squid-image from `egress_proxy_image` or `--egressproxyimage`). `example.com` allows exactly this host, `.example.com` the domain and all of its subdomains. An empty section `AllowedDomains` blocks the network-access completely. Configurations without this section are unchanged (unrestricted network-access). See the section "Network access" of `RunAgentInSandbox.md`.
- `scbuildcodeunits` now also sets `egress_proxy_image` in `<repository>/.ScriptCollection/AgentSandboxConfiguration.ini` to the image `Squid` of `<repository>/.ScriptCollection/OCIImages/ImageDefinition.csv` (if defined), like it does for `image` and `SCBuilder`.
