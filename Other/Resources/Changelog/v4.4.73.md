# Release notes

## Changes

- Linting of the repository:
  - Formatted the markdown-files (one sentence per line, blank lines around blocks, padded table-cells); the content was not changed.
  - Fixed typos and British spellings in the documentation.
  - Fixed and suppressed (false-positive) pylint-findings in the testcases.
- Remote-build: a job can get environment-variables (header `X-Environment-Variables`), which the runner sets only for the program of the job and does not log. This is the way to give a secret to a build-step. `TFCPS_RemoteBuild.run_program_on_runner` and `TFCPS_CodeUnitSpecific_Base.run_program_on_remote_runner` have the new parameter `environment_variables`. A client refuses a runner which does not support environment-variables if it sends some.
- Android (`TFCPS_CodeUnitSpecific_Android`): a productive build signs the release-build with the upload-key from the environment-variables `Android_Signing_Keystore` (base64), `Android_Signing_StorePassword`, `Android_Signing_KeyAlias` and `Android_Signing_KeyPassword`, so the app-bundle can be uploaded to Google Play, and verifies that it is not signed with the debug-key. Every other build stays signed with the debug-key (fixes OTH-4).
- Remote-build: the runner (`SCTaskRunnerServer`) provides the endpoint `GET /metrics` (basic-auth required), which returns the amount of currently running jobs as the Prometheus-gauge `sctaskrunner_running_jobs`.
