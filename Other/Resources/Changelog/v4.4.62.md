# Release notes

## Changes

- Added `GeneralUtilities.get_media_file_inconsistencies` and `GeneralUtilities.assert_media_file_is_consistent` which check whether a media-file (for example mp4 or mkv) can be played completely: The container must be readable and declare a duration, every video- and audio-stream must start and end in line with the declared duration and must not have a gap longer than `GeneralUtilities.media_check_tolerance_in_seconds`; optionally all streams are decoded completely. Added the commandline-command `sccheckmediafile` (`--decode` for the additional decoding) which exits with 0 if and only if no inconsistency was found.
