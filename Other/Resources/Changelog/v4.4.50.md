# Release notes

## Changes

- non-code-update
- Collected all findings in the findings-table in "Other/Reference/Reference.md" with ids of the form "<prefix>-<number>" (SEC, BUG, PER, OTH).
- Fixed an argument-injection in "scruncommandinfolder": an actual folder which contains spaces could add further arguments to the command and thereby bypass the base-folder- and excluded-folder-restriction.
- Secrets (twine-token, NuGet-api-key, NuGet-source-password, openssl-passwords, 7z-password) are not written to the build-log and to exception-messages anymore.
- Deleting a folder does not change the permissions of the targets of symbolic links inside it anymore.
- Fixed several bugs in "ScriptCollectionCore" (file-permission-parsing, inverted symlink-flag of "set_owner", endless recursion when checking registry-images, git-helper-functions, iso-creation, extraction of password-protected archives) and in "ProcessesRunner".
