# Release notes

## Changes

- Fixed that a containerized build (`scbuildcodeunits -c`, `scbuildcodeunitsc`) and a containerized dependency-update (`scupdatedependencies -c`) ignored the given target-environment-type: it was not passed into the container, so the build inside the container always ran with the default `QualityCheck` (for example `-e Productive -c` built as `QualityCheck`).
