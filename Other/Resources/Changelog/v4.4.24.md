# Release notes

## Changes

- Added `ScriptCollectionCore.get_latest_apk_package_version_in_alpine(image, package)`: it returns the latest version of an apk-package which is available in the given alpine-image. It is the alpine-counterpart of `get_latest_apt_package_version_in_debian` and is what the `UpdateDependencies.py` of an alpine-based image-codeunit needs to pin the version of a package it installs
- Fixed `scaddimagetocustomregistry`: the argument-parser defined the short-option `-r` twice (for `--remotehub` and for the never-used `--removeimagelocally`), so every call of the program aborted with `argparse.ArgumentError: argument -r/--removeimagelocally: conflicting option string: -r`. The unused `--removeimagelocally`-argument was removed
