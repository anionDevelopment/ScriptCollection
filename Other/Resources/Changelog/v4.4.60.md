# Release notes

## Changes

- Added the static functions `TFCPS_Tools_General.get_common_project_structure_namespace(common_project_structure_version)` and `TFCPS_Tools_General.get_common_project_structure_xsd_base_url(common_project_structure_version)`, which are now used internally. The constants `CommonProjectStructureNamespace` and `CommonProjectStructureXSDBaseURL` are kept for compatibility and are derived from these functions.
- The GRYLibrary used by the t4-transformation is now the latest release according to the GitHub-releases of GRYLibrary (new method `TFCPS_Tools_General.get_tag_of_latest_github_release`). Fixed the name of the downloaded artifacts-archive (`GRYLibrary_Artifacts_v<version>.zip`) and the paths inside the extracted archive.
