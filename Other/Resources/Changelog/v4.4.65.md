# Release notes

## Changes

- Unified spelling to American English in skills and specifications and clarified the changelog-section of the ScriptCollection-skill.
- Fixed `scbuildcodeunits -c` and `scbuildcodeunitsc` when they are run in a container whose docker-socket is forwarded to the docker-daemon of the host (for example in the `scrais`-sandbox with `-d`): the build-container previously received an empty folder instead of the repository and failed with `is not a git-repository`. It now gets the volumes of the own container (`--volumes-from`), and files which are normally mounted from the configuration-folder are copied into it.
- Added the switches `-m`/`--addreadytomergeflag` and `-f`/`--fastlane` to `scupdatedependencies` and `scupdatedependenciesc`. They are forwarded into the container when the update runs there.
- Findings with the state `accepted` are now struck through in the findings-table like findings with the state `fixed`.
