# Release notes

## Changes

- Docker-codeunits: the image-archive (`<codeunit>/Other/Artifacts/BuildResult_OCIImage/<codeunit>_v<version>_<platform>.tar`) is not written into the artifacts-folder by docker directly anymore. Docker writes it into a temporary folder first and the finished file is moved to the artifacts-folder afterwards. This fixes builds of large images in a container which failed with `failed to receive status: rpc error: code = Unavailable desc = error reading from server: EOF` while the image-archive was written into the artifacts-folder mounted from the host.
