# Release notes

## Changes

- improvement.
- `start_rtsp_test_stream` and `create_test_stream_video` got the parameter `background_color`. The background of a
  test-stream was fixed to black before, which a product can not change although the picture of a test-stream is what
  its testcases compare against. The default is `black`, so a caller which does not pass the parameter gets exactly
  the same picture as before. The value is restricted to letters, digits and the number-sign, because it is put into
  the description of the lavfi-source of ffmpeg, whose parts are separated by colons.
