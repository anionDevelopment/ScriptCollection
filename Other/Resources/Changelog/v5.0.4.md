# Release notes

## Changes

- fix
- Encrypted containers (`scinitencryptedcontainerinrepo`, `scdecryptinrepo`, `scencryptinrepo`): the location of the container-file can not be configured anymore, it is always `.ScriptCollection/SensitiveDataContainer/<Name>.bin`, so the column `File` was removed from `.ScriptCollection/EncryptedFolders.csv` (columns now: `Name;Target`; names may only contain letters, digits, `-`, `_` and `.`). `scinitencryptedcontainerinrepo` has the new mandatory argument `--target` and adds the line `<Name>;<Target>` to the definition-file (which is created if it does not exist).
- Encrypted containers: the password is given either with `--password` or interactively with `--interactive`/`-i` (exactly one of both is required); `scinitencryptedcontainerinrepo` requests an interactive password twice.
