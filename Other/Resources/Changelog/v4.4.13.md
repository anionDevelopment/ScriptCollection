# Release notes

## Changes

- `TFCPS_CodeUnitSpecific_Flutter_Functions.do_common_tasks` now accepts an optional `package_name`: when given, the codeunit-version is written into that package's `pubspec.yaml` too, so a flutter/dart-codeunit's package-version stays in sync with its codeunit-version the same way a .NET-codeunit's csproj-version already does. Existing callers which do not pass `package_name` are unaffected.
- `GeneralUtilities.normalize_path` now collapses repeated path separators inside a path while preserving a leading separator block, so inputs like `C//Temp` become `C/Temp` and `//server//share` stay valid UNC-style paths.
- Added explicit Windows and Linux tests for the separator collapsing behavior of `GeneralUtilities.__sanitize`.
- `TFCPS_CodeUnitSpecific_Base.copy_source_files_to_output_directory` now reads the source-file-list via `git ls-files` instead of `git ls-tree -r HEAD --name-only`, so a file which is only staged (not yet committed) is recognized too. Previously a freshly scaffolded codeunit produced an empty "SourceCode"-artifact until its files were committed.
