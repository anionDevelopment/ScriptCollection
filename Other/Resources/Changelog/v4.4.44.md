# Release notes

## Changes

- The commandline-tools "scbuildcodeunits", "scbuildcodeunitsc", "scupdatedependencies" and "scupdatedependenciesc" now mount the outermost superproject into the container when "-b"/"--basemountfolder" is not set and the repository is a git-submodule. Before, only the submodule itself was mounted, so its real git-folder (which is located in the git-folder of the superproject) was not available inside the container and the build aborted with "fatal: not a git repository". For repositories which are not a submodule nothing changes.
- The test-step of .NET-codeunits now searches the coverage-file in the results-directory of "dotnet test" instead of taking the last line of its output. Before, the build aborted with "File '...warning NETSDK1194...' does not exist." when "dotnet test" printed further lines (for example the warning NETSDK1194) after the path of the coverage-file.
