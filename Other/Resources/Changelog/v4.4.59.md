# Release notes

## Changes

- Changed the common-project-structure-namespace from the versionless `.../tree/main/...` to the version-pinned `.../tree/v3.0.4/...`. The common-project-structure-version is now defined centrally in `TFCPS_Tools_General` (`CommonProjectStructureVersion`); the namespace and the xsd-base-url are derived from that single value, and `supported_codeunitspecificationversion`, all xpath-queries and the generated `codeunit`-, `constant`-, `artifactsinformation`- and `productinformation`-xml-files now use it. A future bump of the common-project-structure-version therefore only has to be done in that one place.
