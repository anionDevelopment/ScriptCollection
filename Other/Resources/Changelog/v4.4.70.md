# Release notes

## Changes

- New command-line-tool `scwebp2png`: converts a webp-file (`-i`) to a png-file (`-o`). `-o` is optional; if it is not specified, the png-file is created in the folder of the input-file with the filename of the input-file and the extension `.png`. Relative paths are resolved relative to the current working-directory. An existing output-file is only overwritten if `-r`/`--replace` is specified, otherwise the conversion fails. If the webp-file is animated, only the first frame is converted.
- The linting of Docker-codeunits logs a warning if the `Dockerfile` of the codeunit does not contain a `HEALTHCHECK`-instruction. `HEALTHCHECK NONE` does not count as a healthcheck.
- The build of .NET-codeunits (`TFCPS_CodeUnitSpecific_DotNet_Functions.build`) has the new mandatory parameter `enable_windows_targeting_on_linux`. If it is `True`, the host is Linux and a runtime of the codeunit is a Windows-runtime (`win-...`), the restore and the build of that runtime are run with `EnableWindowsTargeting=true`, so that for example Windows Forms-codeunits can be compiled for Windows on Linux. The result can still only be executed on Windows. Existing calls of `build(...)`, `standardized_tasks_build_for_dotnet_project(...)` and `standardized_tasks_build_for_dotnet_library_project(...)` have to pass the new parameter.
