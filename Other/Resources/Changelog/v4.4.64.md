# Release notes

## Changes

- Added the `scrais`-option `-d`/`--mountdockersocket` which mounts the docker-socket of the host (`/var/run/docker.sock`) into the sandbox so that the agent can use docker. It can only be set via the commandline (not in the configuration-file), prints a warning to stderr and makes the restrictions of the sandbox ineffective.
- Added `-s` as short-option for the `scrais`-option `--dropcapabilities`.
- `scbuildcodeunits` now sets the value `image` in `<repository>/.ScriptCollection/AgentSandboxConfiguration.ini` to the SCBuilder-image defined in `<repository>/.ScriptCollection/OCIImages/ImageDefinition.csv` during the build, so that the agent-sandbox uses the image which is pinned for the repository.
