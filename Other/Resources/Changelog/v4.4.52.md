# Release notes

## Changes

- Fixed that `TFCPS_VisualRegressionTests.run(update_baselines=True)` failed whenever it actually created or changed a baseline-screenshot. Since playwright 1.50 the `--update-snapshots`-run reports every testcase whose screenshot it created or changed as failed and returns a non-zero exit-code; the update-mode now discards that exit-code and instead compares the freshly written baselines with a second run, so it only fails if a screenshot could not be produced at all (for example because the page did not load) and no longer when images change or are added (which is the purpose of that mode).
