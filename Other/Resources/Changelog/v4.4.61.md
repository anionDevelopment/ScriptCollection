# Release notes

## Changes

- Fixed `TFCPS_Tools_General.__add_github_api_key_if_available` so that trailing whitespace (in particular a trailing newline) in either the `GITHUB_TOKEN` environment-variable or in `~/.github/token.txt` no longer corrupts the `Authorization`-header. Before, such a token-file (which is the common state after writing a token with most editors or piping it from `gh auth token`) made every GitHub-API-call fall back to the anonymous 60/h rate-limit, which could abort a build with `403 Forbidden` (observed in `__ensure_grylibrary_is_available`). An empty `GITHUB_TOKEN` now also falls through to the token-file instead of sending an empty `Bearer`-header.
