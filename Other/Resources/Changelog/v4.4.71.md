# Release notes

## Changes

- `ScriptCollectionCore.push_nuget_build_artifact` (and therefore `TFCPS_Tools_General.push_nuget_build_artifact`) runs `dotnet nuget push` from the temp-folder and passes the package by its absolute path. Before, the push was run in the folder of the package, so a `NuGet.config` of the repository which contains `<clear />` hid the package-sources of the user-level-configuration and a source which was given by its name was reported as invalid.
