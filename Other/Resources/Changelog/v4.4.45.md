# Release notes

## Changes

- fix
- Added a repository-check for typos using codespell to the project-linting of scbuildcodeunits. Findings are reported as warnings only.
- Fixed the typos found by codespell in code and documentation. The public names `download_all_cachable_tools` and `scdownloadcachabletools` were kept unchanged for compatibility.
- Added `.codespellrc` which excludes git-ignored build-results and generated files from the typo-check.
- Removed a useless `return` in the codespell-check (pylint R1711).
- Added testcases for `GeneralUtilities.generate_password`.
- Documented codespell in the required tools.
