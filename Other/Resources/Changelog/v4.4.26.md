# Release notes

## Changes

- Fixed that `create_deb_package` (and therefore `create_deb_package_for_artifact`) always failed on linux with `tar: *: Cannot stat: No such file or directory` and exitcode 2: the content of the control-folder and of the data-folder was passed to `tar` as the wildcard `*`, but programs are started without a shell (`shell=False`), so the wildcard was never expanded and was treated as a literal filename. The folder-content is passed as `.` now. On windows the problem was not visible because the msys-based `tar` expands wildcards on its own
