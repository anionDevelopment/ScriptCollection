# Release notes

## Changes

- fixed the schema-validation of a codeunit-file: the complete "xsi:schemaLocation"-value (which consists of the namespace and the address of the xsd-file) was passed to xmlschema as schema-source, so xmlschema downloaded the namespace-uri (which is a html-page) instead of the xsd-file and every codeunit-file-validation failed with "invalid XML syntax: mismatched tag". Only the address of the xsd-file is passed now
- the validation of a codeunit-file now also checks that its "xsi:schemaLocation" references the xsd-file of exactly the codeunit-specification-version which the codeunit-file declares
- added the enum "TestKind" (ScriptCollection.TestKind), which is generated from the TestKind-enum of GRYLibrary, so both products use the same test-kinds (same names, same comments and same values)
