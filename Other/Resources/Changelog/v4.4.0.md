# Release notes

## Changes

- added fastlane option
- increased the default-timeout of the testcases-run of a dotnet-codeunit from 600 to 1800 seconds
- fixed the arguments of the build which collects the linting-diagnostics of a dotnet-codeunit: they were passed as a string with hand-written quotes, which run_program does not interpret, so the quotes became part of the value of the "-o"-argument and the msbuild-task GenerateDepsFile failed on windows
- fixed TFCPS_Tools_General.write_version_to_codeunit_file: it replaced the version textually and only matched the tag-form with a namespace-prefix ("<cps:version>"), so it silently did nothing after the codeunit-files were converted to declare the namespace as default-namespace ("<version>"). The version-element is set in the parsed document now (which is independent of the prefix), and a codeunit-file without a version-element is reported instead of being ignored. Because of this the version in the codeunit-files stayed at the value it had at the time of that conversion, which let the linting report a mismatch of the version in the csproj-files (which is written on every build) and let the container-images of a codeunit be tagged with an outdated version
