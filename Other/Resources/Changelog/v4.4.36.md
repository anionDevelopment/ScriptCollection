# Release notes

## Changes

- Fixed `run_program_argsasarray_async`: the standard-output and the standard-error of the started program were connected
  to pipes of the calling process, although nobody reads the pipes of a program which is started asynchronously. Such a
  program was therefore stopped as soon as its pipe was full and terminated as soon as the calling process ended and closed
  its end of the pipe, even though it is started to outlive that process. A stream which was started by
  `start_rtsp_test_stream` for example died immediately when the python-process which started it ended. The standard-output
  and the standard-error of an asynchronously started program are discarded now.
- Replaced the deprecated `License ::` classifier in `pyproject.toml` with the SPDX `license = "GPL-3.0-only"`
  field, which removed the `SetuptoolsDeprecationWarning: License classifiers are deprecated.` warning that
  `scbuildcodeunitsc` raised while building the package.
