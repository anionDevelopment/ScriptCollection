# Release notes

## Changes

- The findings of the OCI-image-secret-scan which are known false positives are declared in "<repository>/.ScriptCollection/SecretScanConfiguration.toml" now instead of in "<repository>/.betterleaks.toml". The image-scan is implemented by ScriptCollection itself, so its configuration does not belong into the configuration-file of the third-party-tool betterleaks, which never sees those entries. The file is optional: a repository without any known false positive does not need it. The entries are "[[ignoredfindings]]"-entries with a "description" and a list of "regexes"; they are matched against the finding-description exactly as the former "[[allowlists]]"-entries were, so an existing entry only has to be moved and renamed. The repository-scan keeps using "<repository>/.betterleaks.toml", because it is performed by betterleaks.
- The testcases of the OCI-image-secret-scan declare their placeholder-private-key once instead of once per testcase, and "ScriptCollectionTests/test_TFCPS_OCIImageSecretScan.py" is allowlisted in ".betterleaks.toml". The testcases of a secret-scan have to contain the patterns that scan looks for, otherwise they could not check that it detects them, so the repository-scan reported its own testdata.
