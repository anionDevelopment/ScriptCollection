# Release notes

## Changes

- aded helper for visual regression tests in tfcps
- the helper for visual regression tests now preserves the expected, the actual and the differing screenshot of every failed testcase in "Other/Artifacts/VisualRegressionTestFailures/&lt;timestamp&gt;", because playwright empties its output-folder at the beginning of every run, so the screenshots of a testcase which fails only sporadically were lost with the next run
- added the enum "TestKind" (ScriptCollection.TestKind), which is generated from the TestKind-enum of GRYLibrary, so both products use the same test-kinds (same names, same comments and same values)
- the helper for visual regression tests got the two checks "check_layouts_are_similar" and "check_screenshots_are_similar", which compare the browsers with each other. Until now every screenshot was only ever compared with the baseline-screenshot of its own browser, so a page which looks different in one browser than in the others stayed unnoticed. "check_layouts_are_similar" compares the position and the size of every element of every checked page (which the testcases write down while they run); it is the check which detects a misplaced part of a page. "check_screenshots_are_similar" compares the baseline-screenshots themselves after downscaling them; it is coarse on purpose and detects a missing picture, a different page-height or a completely different page. The reason for the split is that the engines rasterize text differently: even on a page which looks the same thousands of pixels differ, so a pure comparison of the screenshots needs a threshold which is too high to detect a part of a page which moved
- the helper for visual regression tests accepts the parameter "playwright_project" now, which restricts a run to one project of the playwright-configuration (which is one browser). Codeunits whose testcases change the state of the application under test need this: they have to start the application newly for every browser, because otherwise the second browser would find the state which the first one left behind and would therefore see other pages than the first one
