# Release notes

## Changes

- Fixed garbled non-ascii-characters (e.g. umlauts) in the output of programs started by ScriptCollection on Windows (e.g. author-names read from `git log`, which made the developer-team-check fail). The output is now decoded as UTF-8 and only if it is not valid UTF-8 the encoding of the system-locale is used as fallback. Enabling the Windows-option "Beta: Use Unicode UTF-8 for worldwide language support" is not required anymore.
