# Release notes

## Changes

- Added `TFCPS_CodeUnitSpecific_Flutter_Functions.run_visual_regression_tests_in_container`, which runs the visual-regression-tests of a flutter-codeunit (`flutter test --tags visual-regression --run-skipped <folder>`, optionally with `--update-goldens`) in a sibling-container of the `SCBuilder`-image so that the rendered images and their baselines are reproducible independently of the host. Like `__build_linux_in_container` and `TFCPS_VisualRegressionTests` it shares the codeunit with the sibling-container via `--volumes-from` instead of a bind-mount when it already runs inside a container (for example a `scbuildcodeunits -c`-run): a bind-mount of a path of the build-container would otherwise be resolved by the forwarded host-daemon to an empty directory, which made `flutter` abort with `Expected to find project root in current working directory.`.
