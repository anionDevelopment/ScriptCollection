# Release notes

## Changes

- Fixed `do_npm_install` reusing a cached `node_modules` after `package.json` or `package-lock.json` was changed (e.g. after a dependency-update), which made builds run with the outdated packages of the previous install. The cache-marker in `node_modules` is now named `.sc_install_fingerprint` and contains the platform and the sha256-hashes of `package.json` and `package-lock.json`, so `node_modules` is only reused when all of them are unchanged. Existing `node_modules`-folders get installed again once because of the new marker.
- The codespell-check of `scbuildcodeunits` now only checks files which are not git-ignored, so git-ignored content like `node_modules` or the artifacts-folders of the codeunits is not checked anymore. Hidden files and folders which are not git-ignored (for example `.github`) are checked now too. The files are passed to codespell using a file-list (`@<file-list>`), so codespell is called only once, even for repositories with a lot of files. `.ScriptCollection/CodeSpellIgnore.txt` can still be used to ignore folders which are committed.
