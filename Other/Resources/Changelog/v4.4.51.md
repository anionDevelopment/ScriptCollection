# Release notes

## Changes

- Added `TFCPS_Tools_General.update_visual_regression_baselines_of_all_codeunits(repository_folder)`: it runs, for every codeunit of the repository which has one, that codeunit's `Other/QualityCheck/UpdateVisualRegressionBaselines.py` (and skips codeunits which have none), so a repository can update the visual-regression-baseline-images of all of its codeunits with a single call without listing the codeunits anywhere. A repository uses it from one `Other/Scripts/UpdateVisualRegressionBaselines.py` which a single workspace-task calls.
