# Release notes

## Changes

- `scrais` can give the sandbox the same build-environment as a build-container of `scbuildcodeunits -c` (required environment-variables, `TFCPS`-folder, custom scripts, image-registries, trusted root-CAs and registered package-sources), so the agent can use private package-sources. It is opt-in: `provide_build_environment = true` in `AgentSandboxConfiguration.ini` or `-b true`. It requires an image with ScriptCollection `4.4.68` or newer. See the section "Build-environment" of `RunAgentInSandbox.md`.
- New command-line-tool `scregisterpackagesources`: registers the package-sources which are declared by the environment-variables `Dependency_<technology>_<name>_*` exactly like a .NET-codeunit-build does it. See the section "Package-sources" of `ConfigurationFolder.md`.
